Privacy Policy

Effective Date: September 4, 2026 • App Version: CutOut Seller v1.3.0 (versionCode: 4) • Developer: Vrit

1. Introduction and Philosophy

CutOut Seller values user privacy and data security above all else. The application is built on an On-Device First architecture, ensuring online sellers and creators can remove backgrounds, edit product photos, and prepare marketplace listings quickly and securely without relying on cloud processing or transmitting user media to external servers.

2. Data Processing Architecture

CutOut Seller operates under the following data principles:

  • Product Photos & Media: Photos imported from the device gallery or captured using the camera are processed strictly inside local device memory. Zero Uploads: CutOut Seller does not upload original photos, segmentation masks, or edited deliverables to CutOut Seller servers or any third-party cloud infrastructure.
  • On-Device Artificial Intelligence: Background removal AI models (IS-Net and U²-Net) are bundled directly inside the application installation package. Neural network inference is executed 100% locally on your device CPU via ONNX Runtime.
  • Local Projects and Autosaves: User projects, editing history, canvas states, and crash recovery autosaves are stored solely in the application's local sandbox (Local Sembast Database). No cloud storage is utilized.
  • Preferences and Settings: User preferences such as language, theme mode, default quality, and export format are stored in local device preferences.

3. Device Permissions

CutOut Seller requests only minimal, purpose-specific permissions based strictly on user requests:

  • Camera (CAMERA): Requested solely when you choose to take a product photo directly within the app. Permission can be granted or revoked at any time via system settings.
  • Photos / Media Picker (Scoped Storage): Employs the standard Android system photo picker to let users select specific images. The app only accesses files explicitly chosen by the user and never requests broad device storage permissions (no MANAGE_EXTERNAL_STORAGE).
  • Network / Internet: The release version of the application functions 100% offline and does not require internet connectivity for photo editing operations.

4. User Accounts

CutOut Seller requires no user accounts. No registration, login, phone number, email address, or identity verification is required to use the application.

5. Analytics, Advertising & Telemetry

  • Zero Third-Party Analytics: CutOut Seller does not integrate Google Analytics, Firebase Analytics, Mixpanel, or any behavioral tracking SDKs.
  • Zero Advertising: The app contains no third-party ad networks or ad identifiers.
  • Zero Remote Telemetry: Crash recovery is handled locally; error logs are never transmitted to remote servers.

6. Payment Information

In version v1.3.0, the "CutOut Seller Pro" tier is marked as Coming Soon. The app contains no payment gateway, no Google Play Billing library, and does not collect any credit card, bank, or transaction data.

7. Data Retention & Deletion

Users retain complete control over all data generated and stored on the device:

  1. Single Project Deletion: Remove individual projects from the project gallery at any time.
  2. Bulk Clear: Use the "Delete all projects" or "Clear export cache" options located in Settings.
  3. App Clear Data / Uninstall: Clearing app data in system settings or uninstalling CutOut Seller completely deletes all locally stored projects, database files, and caches via standard Android sandbox cleanup.

8. Children's Privacy

CutOut Seller is a general-purpose product photo editing utility. It does not knowingly collect or solicit personal data from children under the age of 13.

9. Updates to This Policy

Should future versions introduce cloud synchronization, accounts, or payment options, this Privacy Policy will be revised and posted transparently in advance within the application and on the Google Play Store listing.
